# Black Screen TV — APK via GitHub Actions (kostenlos, kein PC nötig)

## So bekommst du die fertige APK in ~5 Minuten

### Schritt 1 — GitHub Account erstellen
👉 https://github.com/signup (kostenlos, auch auf dem Smartphone)

### Schritt 2 — Neues Repository erstellen
1. Auf github.com einloggen
2. Oben rechts auf + → New repository
3. Name: BlackScreenTV, Public auswählen
4. Create repository klicken

### Schritt 3 — Dateien hochladen
1. ZIP entpacken, alle Dateien ins Repository hochladen
2. "Commit changes" klicken → Build startet automatisch

### Schritt 4 — APK herunterladen
1. Tab "Actions" → fertiger Build → unten "Artifacts"
2. "BlackScreen-TV" herunterladen → enthält app-debug.apk

Gesamtdauer: ca. 3-5 Minuten
